# BlackjackAgent
Uses Q-Learning to train a bot on optimal policy in Blackjack.

# Changing parameters
To change parameters, change the default values in __init__ for the QLearningAgent class.

# Run instructions
Currently, the program is set up to output videos for all agent evaluation episodes and to output a graph for the 
overall mean rewards during training. These can be disabled by commenting out, and then running the program normally.
